* ဘေးတစ်စောင်း ဘရိတ်တူမူ: ဘေးတစ်စောင်း ဘရိတ်တူ ထွက်ခဲ့ပါက နက္ခတ် နှင့် ပြန်ကျဂဏန်း ကို ပြန်လည်ကစားရမည်။
(ခ) 9:30 Modern နှင့် Internet အထူးမူများ
* ထိပ်စီးတူလျှင်: ၉:၃၀ ထွက် Modern / Internet ထိပ်စီးတူလျှင် အပူး (သို့မဟုတ်) 0 ထွက်တတ်သည်။
* ထိပ်တူ (သို့မဟုတ်) ပိတ်တူလျှင်: Modern နှင့် Internet ထွက်ဂဏန်း ထိပ်တူ (သို့မဟုတ်) ပိတ်တူလျှင် 0 (သို့မဟုတ်) အပူး ထွက်တတ်သည်။
* ဘရိတ်တူလျှင်: Modern နှင့် Internet ထွက်ဂဏန်း ဘရိတ်တူလျှင် 0 ၊ အပူး ၊ ပြန်ကျ ထဲမှ တစ်ခုခု ထွက်တတ်သည်။
(ဂ) 2D ဝေါဟာရ ဗဟုသုတ (အလယ်သတ်ကွင်း ရှင်းလင်းချက်)
* အလယ်သတ်ကွင်း ဆိုသည်မှာ: အလယ်ဂဏန်း ၄ လုံးက ၁ လုံးတည်း (သို့မဟုတ်) ၂ လုံးတည်း ဖြစ်ပြီး အထက်/အောက် တူနေတာမျိုးကို ခေါ်ပါသည်။
* အထူးလက္ခဏာ: အလယ် ထက်/အောက် ဘရိတ်တူတာက မူသစ်သဘောရှိပြီး အနည်းငယ် ဆင်တူနေတတ်သည်။
