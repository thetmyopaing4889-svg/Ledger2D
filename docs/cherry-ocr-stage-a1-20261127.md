# Stage A.1 — isolated first benchmark build
Baseline: Build 1985 (afa77be118dd5b4c1129b3db6a3a35853e2badb6). Original :app source unchanged; :ocrbenchmark only included with -PocrBenchmark=true. Separate package com.myanmar.cherryocrbenchmark; no ledger or network permission. targetSdk 32 for private initial benchmark, minSdk 26; verify actual ABI/page size on device before shipping. This is not the production OCR feature.
Implemented: Tesseract4Android standard 4.9.0 (JitPack), pinned tessdata_fast/best release commits with Git blob verification + SHA256 manifest; bundled ML Kit Latin 16.0.1. Build-only network model fetching. 20 synthetic samples, SAF multiple crops, optional exact ground truth, identical selected images for comparison, 1/5/10/20 or all and repeat 1/3/5, lazy sequential recognition, per-image errors, bounded bitmap decode, cancel between images, per-trial timings and sampled PSS/native/Java, JSON local export, raw and normalized edit distance and ordered line distance. No silent missing image.
Limitations: Myanmar CRNN NOT_RUN (model line segmentation, exact charset/CTC decode and runtime still pending); this is A.1, NOT Gate A completion. Actual APK build and device airplane-mode timings not yet established. No claim of fresh-process cold runs; repeat trials initialize new engines and first inference may include lazy init. Source image bitmap preview and exact text annotations; no parser/amount-specific scoring yet, no CSV, no independent holdout or real device tests yet. Synthetic images are rendered chat-like text, not real Messenger/Viber. No production engine recommendation. Do not use real customer screenshots in repo or upload unredacted JSON. Build sources: https://github.com/adaptech-cz/Tesseract4Android/releases ; https://github.com/tesseract-ocr/tessdata_fast/releases ; https://github.com/tesseract-ocr/tessdata_best/releases ; https://developers.google.com/ml-kit/vision/text-recognition/v2/android ; https://huggingface.co/ksithu/myanmar-crnn-ocr .
